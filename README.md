# 把话说尽 · 书站

一个纯静态的中文书站。没有框架、没有外链字体、没有构建依赖，只用 Python 标准库。

## 结构

```
book-site/
├── book.json          # 书名、目录、章节清单（哪章写了、在哪一章）
├── content/           # 正文，一章一个 Markdown 文件
│   ├── about.md       # 序
│   └── ch01.md        # 第一章
├── assets/
│   ├── style.css      # 全部样式
│   └── favicon.svg
├── build.py           # 生成器
├── dist/              # 生成结果，上线就传这个目录
├── 把话说尽-单文件版.html   # 全书打包成一个文件（送人 / 存档 / 转 PDF）
└── 部署说明.md        # 怎么上线，看这个
```

## 用法

```bash
python3 build.py                      # 重新生成 dist/
cd dist && python3 -m http.server 8000  # 本地预览 http://localhost:8000
```

## 加一章

1. 新建 `content/ch02.md`，第一行写 `# 第二章　给万物一个称呼`
2. `book.json` 里给第二章加 `"file": "ch02.md"`
3. `python3 build.py`

目录、待写标记、上一章 / 下一章、字数与阅读时间会自动更新。

## 排版约定

- 正文用宋体，19px，行高 1.95，首行缩进 2em
- 强调用 `**粗体**`，不划荧光笔——中文书没有这个传统
- 引号一律用中文全角 `“”`，代码块里保持英文 `"`
- 一章一个概念，每章末尾三句话总结

## 支持的 Markdown

标题、段落、`**粗体**`、`*斜体*`、`` `行内代码` ``、代码块、引用、表格、分隔线、`- 列表`。
够用，不多不少。
